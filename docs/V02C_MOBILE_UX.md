# v0.2-C 모바일·지도 가독성

FR-01/09/14/15/18, WEB-02/05/08의 표시·탐색 개선이다. v0.2-B를 로컬 커밋으로 보존한 뒤 feat/v02c-mobile-ux에서 진행한다. API/DB/작업 처리/인증·의미 검증·승인 상태 계약을 변경하지 않는다.

## 문서 목록

600px 이하에서 기존 단일 table/row DOM을 세로 카드로 배치한다. 별도의 복제 목록·조회·캐시는 만들지 않는다. 문서명/버전·활성/처리 상태/상세 버튼을 같은 카드에서 모두 확인한다. 제목 행은 접근성 트리에 유지하고 모바일 셀에는 한국어 항목명을 함께 표시한다. 긴 이름은 줄바꿈하며, PC 표는 유지한다.

상세의 등록·활성화·workflow 이동과 직원 조회 제한은 v0.2-B 동작을 그대로 사용한다. 헤더의 긴 기관명은 별도 줄에서 줄바꿈하며 로그아웃·도움말은 단어 단위로 유지한다.

## 업무절차 탐색

900px 이하에서 처음 진입하면 단계 목록을 기본으로 표시한다. 진입 후 화면 크기 변경은 사용자가 선택한 지도/목록 모드를 덮어쓰지 않는다. 단계 선택·원문 패널 이동·포커스·출처 확인과 내용 검토 필요의 분리는 유지한다. 모바일 목록에서도 출처 확인 상태를 숨기지 않는다.

지도는 사용자가 선택할 수 있다. 제목16px/상태13px/보조14px와 세로 간격을 확대한다. 좌표 배치는 탐색용이며 업무 순서·간선·조건·반려·보완 관계를 변경하지 않는다. 확대/축소/전체 보기 버튼과 ‘선택 단계 크게 보기’는44px이며, 선택 단계는1배율로 중심 이동해 읽을 수 있다. 전체 지도 맞춤에서는 노드가 작아질 수 있으므로 목록/큰 보기로 보완한다. 모바일 최초 지도 표시는 전체 맞춤 대신1배율로 시작한다. 지도 내부 이동·확대는 필요하지만 페이지 가로 스크롤은 만들지 않는다.

## 안내와 검토

일반 신뢰 안내를 ‘내용 검토 필요/공식 절차가 아닌 후보’로 간추리고 기존 복구 설명은 ‘작업·복구 안내’로 접는다. 의미/승인 기술 상태는 상세에 유지한다. 기한 null은 ‘확인되지 않음, 기한이 없다는 뜻은 아님’으로 표현한다. 원문 확인 성공 안내의 중복 문장만 제거하며 상태 배지·원문·검토 필요·오류를 유지한다.

전체 ReviewIssue는 제거·필터링하지 않는다. ERROR 또는 auto_block이 하나라도 있으면 전체 검토 목록을 기본 펼침으로 제공한다. 사용자가 접을 수 있지만 심각한 이슈를 임의로 없애거나 의미 검증 완료로 바꾸지 않는다.

## 접근성·성능 검증 경계

320/375/430 및 PC, 긴 이름·버전·권한, 단계 목록 키보드/원문 포커스, 지도 배율/간선, 버튼·요약 터치 영역, 계산된 텍스트 대비, 200% 본문 글자 확대 reflow를 Chromium에서 검사한다. CSS 확대/좁은 viewport 검사는 OS·모바일 실제 기기·모든 native 브라우저 zoom·스크린 리더 검증의 대체가 아니다.

기존 node memo/props 참조 안정화·polling/취소/기관·버전 검사는 유지한다. 지도·목록 전환에 추가 네트워크 요청을 만들지 않으며 100노드 참조 교체0을 기존 회귀로 확인한다. 노드 수 변경·재배치 자체가 실제 절차 의미 정확성의 증거는 아니다. 실 AI/원격 인증·운영 배포 준비도는 기존 미검증 상태다.
