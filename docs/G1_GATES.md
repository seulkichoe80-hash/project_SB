# G1 A B C D 분류와 착수 규칙

기준일 2026-10-16. 사용자의 이번 요청에 따라 이전의 전체 G1 일괄 차단 방식을 적용 시점별로 재분류한다. 과거 PHASE1/인터넷전환 보고서는 당시 판단으로 보존하고 현재 착수 조건은 이 문서를 단일 기준으로 한다. 재분류는 시험 PASS 승격이나 기능 삭제가 아니다. 전체 G1은 미완료다.

## A 핵심 개발을 공통으로 막는 기반

| ID | 진입 조건 | 증거와 한계 |
|---|---|---|
| A-01 | 명확한 Git 루트·제외 규칙·원격/커밋 경계 | 이번 로컬 init/main, .gitignore, 초기 포함/제외 검토. remote/stage/commit 없음 |
| A-02 | 단일 기준 문서·루트 AGENTS/Skill·FR/링크 정합 | 루트 배치와 outputs 연결. Skill 정적/실제 탐색은 별도 결과, AGENTS 다음 세션 주입은 구분 |
| A-03 | 현재 선택 스택 최소 실행 가능성 | 기존 React/Vite/TS/Flow build·FastAPI HTTP·SQLite PASS를 제한 범위로 재사용 |
| A-04 | 공개/합성 원본과 근거 계약 검증 방법 | 완전 합성 HWPX 구조/앵커, JSON schema/근거 검사·부정 입력 시험. AI 의미 정확성/시각 렌더는 B |
| A-05 | 모델 없이도 안전하게 테스트할 경계 | offline 계약·명시 NOT_RUN·빈 서버 .env.example·paid call 차단, 원본 불변·기관/버전 검사 설계 |

A 최종 판정은 outputs/FOUNDATION_REPORT.md와 정적/계약 검사 결과를 따른다. A-02의 기준은 단일 지침의 올바른 배치·형식·링크와 현재 작업에서의 명시 적용이다. 별도 app-server의 런타임 조회/다음 세션 프롬프트 주입 성공까지 확인했다는 뜻은 아니며 차단 결과를 보존한다. A 준비가 확인되면 다음 요청에서 Phase 2의 로컬 자료모델·불변 저장·작업상태·권한 경계 같은 세부 기능부터 구현할 수 있다. 전체 웹앱/해당 B 기능을 한 번에 시작할 권한을 주는 것이 아니다. 이번은 기반/검증만 수행한다.

## B 해당 기능 구현 전에 검증

2026-10-16 Phase 2B 추가 실증: [파서 계약](PHASE2B_PARSING.md)의 제한된 PDF/HWPX 논리 구조·원문 앵커·영속 작업은 구현/시험했다. 신규34+기존33 전체67 PASS 및 합성 PDF10/HWPX17 앵커 재해결 증거는 [새 보고](../outputs/PHASE2B_REPORT.md)다. 아래 B-01의 **한컴 시각 순서·페이지/대표 corpus는 여전히 미검증**이다. 논리 XML 지원을 시각/의미 정확성이나 B-01 전체 통과로 대체하지 않는다. B-02~05·C·D의 미실행 상태도 유지한다.

B 실패는 해당 기능을 차단한다. 서로 독립적인 저장/메타데이터 기능의 착수를 무조건 막지 않는다. 단 모든 API/스토리지 기능은 원본 불변·권한·기관/버전 경계 시험이 기본 수용 조건이다. B에 필요한 최소 스파이크는 실제 기능 구현보다 먼저 수행한다.

## C 운영 배포 전에 검증

HTTPS·정확 CORS·Auth/JWT/멤버십/역할·secret/backend only·rate/비용 reservation·악성 업로드·prompt injection·PostgreSQL/객체 저장 영속성·migrations/worker 복구·재시작/재배포·DB/객체 백업/복원·저장기간·플랜/비용·콜드스타트를 검증한다. 클라우드 영속 DB/저장소는 이 단계에서 실제 요건/실측으로 확정한다.

현재 전부 미검증/미실행이며 리소스 생성·배포·유료 호출은 별도 승인 필요다. Docker 부재·내부GPU·폐쇄망은 현재 A 조건이 아니다. 이전 G1-C로 부르던 클라우드 실증은 이 C 범주로 이동하며 PASS로 바꾸지 않는다.

## D 공모전 제출 전에 검증

전체 P0·채택 P1 회귀와 동결 대표 골드셋, 실제 2모델·근거/보안 지표, 공개 URL 평가자 브라우저 흐름, 개발자 개입 없는 소스 독립 실행(네이티브 필수·Docker 선택), 비공개 공공 GitLab/심사권한/README·신청서/3~5쪽 안내서/5분 이내 MP4·출처/라이선스/제약·hash/접수 증빙을 검증한다. 제출11/11·11/09 동결·11/10 후보를 유지한다.

현재 D는 미완료다. 단순 fixture·동일 PC·모의 모델 결과를 심사 독립 실행/실 AI 품질로 사용하지 않는다. 최초 커밋은 포함/제외 검토 보고 후 결정하고 remote push/공개 배포는 별도 승인한다.

## Phase 2 단계별 착수 판정

공통 A가 준비되고 해당 작업의 선행 B가 충족되거나 B에 의존하지 않는 작업이면 **그 세부 작업에 한해 착수 가능**하다. 예: 로컬 SQLite 메타데이터/불변 파일 저장·등록 해제·권한 테스트 기반은 실제 유료 LLM/클라우드 생성 없이 시작할 수 있다. 실제 업무지도 UI는 B-04, 의미 검색은 B-03, AI 절차 생성은 B-02 통과 전에 완료 기능으로 구현/시연하지 않는다.

전체 G1 PASS·전체 Phase 2 완료·공개 배포 가능은 현재 선언하지 않는다. 미검증 원문/시각 범위를 임의로 제거하거나 P0를 낮추지 않는다. 기준 충돌은 PRD 범위·현재 사용자 요청·이 분류를 함께 확인한다.
